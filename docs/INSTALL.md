# دليل تثبيت اجوبي PDF

هذا الدليل يشرح تثبيت **اجوبي PDF 1.2.0** على ويندوز خطوة بخطوة، بما في ذلك اختيار اللغة عند بدء التثبيت.

---

## قبل البدء

| النظام | النسخة المطلوبة | ملاحظات |
|---|---|---|
| Windows 10 / 11 | 64-bit | النسخة الكاملة |
| Windows 7 / 8 | 64-bit (ويندوز 7 يتطلب SP1) | تتطلب تحديث [KB2999226](https://support.microsoft.com/help/2999226) (Universal C Runtime) |
| Windows XP | — | غير مدعوم |

- المثبّتات غير موقّعة رقمياً بعد، لذلك قد يظهر تحذير **SmartScreen** من ويندوز.
- حجم ملف ويندوز 10/11 نحو **102 MB**، وملف ويندوز 7/8 نحو **46 MB**.

---

## 1. تنزيل الملف

افتح صفحة **Releases** في المستودع ونزّل الملف المناسب:

- **Windows 10 / 11**: `AjoubyPDF_Setup_win10.exe`
- **Windows 7 / 8**: `AjoubyPDF_Setup_win7.exe`

للتحقق من سلامة التنزيل، افتح PowerShell في مجلد التنزيل وقارن البصمة:

```powershell
Get-FileHash .\AjoubyPDF_Setup_win10.exe -Algorithm SHA256
```

يجب أن تطابق القيمة الموجودة في [SHA256SUMS.txt](../release/SHA256SUMS.txt).

---

## 2. اختيار لغة واجهة التثبيت

عند تشغيل الملف تظهر أولاً نافذة **Select Setup Language**:

1. افتح القائمة المنسدلة واختر **العربية** (أو English).
2. اضغط **OK**.

هذه الخطوة تحدد لغة أزرار المعالج ونصوصه فقط. يمكنك اختيار العربية حتى لو كانت لغة ويندوز إنجليزية.

> إذا ظهر تحذير SmartScreen: اضغط **More info** ثم **Run anyway**.

---

## 3. اختيار لغة البرنامج

تظهر بعدها صفحة **«لغة البرنامج — Application language»** وفيها **19 لغة**:

- العربية، English، Français، Español، Deutsch، Italiano، Português، Türkçe، Русский، 中文، 日本語، 한국어، हिन्दी، Nederlands، Polski، Svenska، Ελληνικά، فارسی، Українська.
- اللغة الافتراضية تُختار تلقائياً حسب لغة واجهة التثبيت، ثم لغة ويندوز، ثم الإنجليزية.
- اللغة التي تختارها هنا هي لغة واجهة البرنامج عند أول تشغيل، وتُحفظ في ملف `language.txt` داخل مجلد التثبيت.

يمكنك تغييرها لاحقاً من قائمة **«اللغة»** داخل البرنامج دون إعادة التثبيت.

> **ملاحظة:** إذا كانت لديك نسخة مثبّتة سابقاً وغيّرت لغتها من داخل البرنامج، فسيحتفظ التحديث باختيارك، إلا إذا اخترت لغة مختلفة في صفحة التثبيت.

---

## 4. إكمال المعالج

1. **مجلد التثبيت**:
   - تثبيت لكل المستخدمين (يتطلب صلاحيات مدير): `C:\Program Files\AjoubyPDF`
   - تثبيت للمستخدم الحالي فقط: `%LOCALAPPDATA%\Programs\AjoubyPDF`
2. **مهام إضافية** (كلها اختيارية):
   - إنشاء اختصار على سطح المكتب.
   - إضافة Ajouby PDF إلى قائمة «فتح باستخدام» لملفات PDF (لا يغيّر القارئ الافتراضي).
   - تشغيل Ajouby PDF بعد انتهاء التثبيت.
3. اضغط **تثبيت** وانتظر حتى ينتهي النسخ.

---

## 5. أول تشغيل

- افتح البرنامج من قائمة ابدأ أو من اختصار سطح المكتب.
- ستجده باللغة التي اخترتها في صفحة التثبيت.
- زر **دليل** أو مفتاح **F1** يفتح دليل الاستخدام داخل البرنامج.
- اسحب أي ملف PDF إلى النافذة لفتحه، أو استخدم بطاقة **«افتح ملفاً»**.

إذا أردت تغيير اللغة: قائمة **«اللغة»** ← اختر اللغة ← تُطبّق فوراً وتُحفظ.

## التثبيت الصامت

لمديري الأنظمة أو التثبيت الجماعي:

```bat
REM تثبيت عربي للمستخدم الحالي دون نوافذ
AjoubyPDF_Setup_win10.exe /SILENT /CURRENTUSER /APPLANG=ar

REM تثبيت إنجليزي لكل المستخدمين (يتطلب مدير)
AjoubyPDF_Setup_win10.exe /SILENT /APPLANG=en

REM بلا واجهة نهائياً
AjoubyPDF_Setup_win10.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART /APPLANG=ja
```

| المعامل | المعنى |
|---|---|
| `/SILENT` | بلا تدخل من المستخدم، مع شريط تقدم |
| `/VERYSILENT` | بلا واجهة إطلاقاً |
| `/CURRENTUSER` | تثبيت للمستخدم الحالي دون صلاحيات مدير |
| `/DIR="D:\Apps\AjoubyPDF"` | مجلد تثبيت مخصص |
| `/LANG=arabic` أو `/LANG=english` | لغة واجهة التثبيت |
| `/APPLANG=ar` | لغة البرنامج (19 رمزاً) |

رموز `/APPLANG`: `ar, en, fr, es, de, it, pt, tr, ru, zh, ja, ko, hi, nl, pl, sv, el, fa, uk`.

## الترقية

- شغّل مثبّت الإصدار الجديد فوق النسخة القديمة؛ لا تحتاج لإزالة التثبيت أولاً.
- تُحفظ إعداداتك (الحجم، الشريط الجانبي، آخر الملفات، اللغة) في `HKCU\Software\Ajouby\Ajouby PDF`.
- إذا اخترت لغة جديدة في صفحة التثبيت، يتغيّر البرنامج إليها. وإذا تركتها كما هي، يبقى اختيارك السابق.

---

## إزالة التثبيت

1. **الإعدادات** ← **التطبيقات** ← **Ajouby PDF** ← **إزالة التثبيت**.
2. أو شغّل `unins000.exe` من مجلد التثبيت.

يزيل المثبّت ملفات البرنامج و`language.txt` والاختصارات. تبقى إعدادات المستخدم في الريجستري عمداً (حجم النافذة، آخر الملفات، اللغة). لإزالتها بالكامل:

```bat
reg delete "HKCU\Software\Ajouby\Ajouby PDF" /f
```

---

## نسخة محمولة

بعد التثبيت يمكنك نسخ مجلد البرنامج كاملاً إلى USB أو قرص آخر وتشغيل `AjoubyPDF.exe` مباشرة. ستعمل كل الوظائف، وستُحفظ الإعدادات في حساب ويندوز الحالي. الملف `language.txt` في المجلد يحدد لغة أول تشغيل.

---

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| تحذير SmartScreen | **More info** ← **Run anyway** (الملف غير موقّع بعد) |
| مضاد الفيروسات يحذف الملف | أضف مجلد البرنامج إلى الاستثناءات؛ هذه إنذارات خاطئة شائعة مع PyInstaller |
| البرنامج لا يبدأ على ويندوز 7 | تأكد من SP1 وتثبيت KB2999226، وأن النسخة 64-bit |
| حروف عربية تظهر مربعات | ثبّت خطاً عربياً مثل Segoe UI أو Tahoma |
| OCR لا يعمل | ثبّت [Tesseract](https://github.com/UB-Mannheim/tesseract/wiki) وأضفه إلى `PATH` |
| «فشل الحفظ» | تأكد أن الملف غير مفتوح في برنامج آخر وأن لديك صلاحية الكتابة في مجلده |
